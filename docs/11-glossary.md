# Technical Glossary: Gourmet Restaurant Hub

- **Lenis**: A modern, lightweight smooth-scroll library that normalizes mouse wheel deltas and provides inertia-based scrolling.
- **Magnetic Button**: A micro-interaction where an element physically tracks the cursor's proximity using vector distance calculations.
- **R3F (React Three Fiber)**: A React renderer for Three.js that brings declarative JSX syntax to WebGL scenes.
- **Three.js**: A cross-browser JavaScript library and API used to create and display animated 3D computer graphics in a web browser using WebGL.
- **WebGL**: A JavaScript API for rendering high-performance interactive 3D and 2D graphics within any compatible web browser without plugins.
